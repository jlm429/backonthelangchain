# Fictional Demo Support Knowledge

This document describes an invented Acme organization procedure for demonstration
only. It is not production guidance.

## Meeting Room Display Recovery

Classification: Fictional demo knowledge.

Question: The Acme meeting room display is awake but does not show scheduled
meetings.

Answer: On the room controller, open RoomLink Diagnostics and select Refresh
Calendar. Wait for LAST SYNC to update, then reload the room display. If the
calendar remains blank, contact Workplace Technology with the room name.
